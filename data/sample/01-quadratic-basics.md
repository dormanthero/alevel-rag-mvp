# 二次方程基础（Quadratic Equations）

## 标准形式
二次方程一般写成：

\[ ax^2 + bx + c = 0 \quad (a \neq 0) \]

其中 \(a\) 为二次项系数，\(b\) 为一次项系数，\(c\) 为常数项。

## 因式分解法（Factorisation）
若能写成 \((px + q)(rx + s) = 0\)，则由零乘积原理得：

\[ px + q = 0 \quad \text{或} \quad rx + s = 0 \]

从而求出两根。例：\(x^2 - 5x + 6 = 0\) → \((x-2)(x-3)=0\) → \(x=2\) 或 \(x=3\)。

## 配方法（Completing the Square）
把 \(ax^2 + bx + c\) 改写成 \(a(x-h)^2 + k\) 的形式，便于求根或看顶点。

步骤概要：
1. 若 \(a \neq 1\)，先提出 \(a\)
2. 对括号内一次项系数的一半平方后加减
3. 整理成完全平方式

例：\(x^2 + 6x + 5 = (x+3)^2 - 9 + 5 = (x+3)^2 - 4\)

## 求根公式（Quadratic Formula）
\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

适用于所有实系数二次方程（在判别式允许时）。

## 判别式（Discriminant）
\[ \Delta = b^2 - 4ac \]

- \(\Delta > 0\)：两个不同实根  
- \(\Delta = 0\)：一个实根（重根）  
- \(\Delta < 0\)：无实根（在实数范围内）

## 学习提示
先判断能否因式分解；不能再配方或用求根公式。做题时先算 \(\Delta\)，再决定有几个实根。
